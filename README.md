# ゆる募

> ゆるく貼って、そっと集まる。

「断られたらどうしよう」という不安を減らすための仲間集めアプリです。
誘う人も、誘われる人も、「断る／断られる」ストレスを感じない仕組みにしています。

- 誘いは特定の 1 人あてではなく、グループに「ゆるく貼る」だけ
- 興味がある人だけが「参加する」を押す（押さなくても誰にも伝わらない）
- **開催が決まるまで、投稿者の名前も反応した人の名前も、誰にも見えない**
- 人数が揃ったら開催確定。そこで初めてメンバーが分かり、グループトークができる
- 締切までに人数が揃わなかったら、誰にも知らせずに静かに終わる

仕様の元になったドキュメントは `docs/` フォルダにあります。

| ファイル | 内容 |
|---|---|
| `docs/requirements.html` | 要件定義書 |
| `docs/design-guide.html` | デザインガイド（案5：手書き・コルクボード） |
| `docs/terms-and-privacy.html` | 利用規約・プライバシーポリシー（ドラフト。アプリ内の `/terms` でも表示） |

## 動かし方

Python 3.10 以上が必要です。

```bash
# 1. （おすすめ）このアプリ専用の環境を作って有効にする
python -m venv .venv
source .venv/bin/activate        # Windows の場合は .venv\Scripts\activate

# 2. 必要なライブラリをインストール
pip install -r requirements.txt

# 3. お試し用のデータを入れる（入れなくても動きます）
python seed_demo.py

# 4. アプリを起動
python app.py
```

ブラウザで http://127.0.0.1:5000 を開きます。
スマホの画面サイズ向けに作っているので、PC で見るときはブラウザの開発者ツールでスマホ表示にすると見やすいです。

### お試し用のアカウント（`seed_demo.py` を実行した場合）

| 電話番号 | 名前 | 状態 |
|---|---|---|
| 090-0000-0001 | たろう | 「朝カフェ」が開催確定ずみ（トークあり） |
| 090-0000-0002 | はなこ | 「夜ごはん」を募集中（1 人反応あり） |
| 090-0000-0003 | じろう | |
| 090-0000-0004 | さくら | |

開発モードでは、SMS の代わりに**認証コードが画面に表示**されます（ターミナルにも出ます）。
ブラウザを 2 つ（片方はシークレットウィンドウなど）使って別々の人でログインすると、
「名前が見えない」「人数だけ増える」「揃ったら開催確定」の流れを試せます。

### テスト

```bash
python -m pytest
```

匿名設計（名前が HTML に出ないこと）、開催確定、静かな終了、不参加連絡、アカウント削除などを確認します。

## ファイルの構成

```
yurubo/
├── app.py            … アプリ本体（URL ごとの処理と、募集のルール）
├── db.py             … データベース（テーブルの定義・接続）
├── seed_demo.py      … お試し用データを入れるスクリプト
├── requirements.txt  … 必要なライブラリの一覧
├── templates/        … 画面の HTML（Jinja2 テンプレート）
│   ├── base.html           … 全画面共通の土台（ボトムナビなど）
│   ├── macros.html         … 何度も使う部品
│   ├── home.html           … 画面1 ホーム（コルクボード）
│   ├── post_new.html       … 画面2 誘いをつくる
│   ├── post_detail.html    … 画面3 募集の詳細
│   ├── chat.html           … 画面4 開催決定後のグループトーク
│   ├── groups.html         … 画面5 見せる相手グループの一覧
│   ├── group_form.html     … 画面6 新しいグループを作る／編集
│   ├── contacts*.html      … 電話帳と、アクセス許可の説明画面
│   ├── login.html / verify.html / signup.html … 電話番号ログイン
│   └── notifications.html / settings.html     … お知らせ・じぶん（アカウント削除）
├── static/style.css  … デザイン（手書き・コルクボード風）
├── tests/            … 自動テスト
└── docs/             … 仕様のドキュメント
```

## 要件定義書の機能との対応

| # | 機能 | どこで実装しているか |
|---|---|---|
| 1 | ゆる募集投稿 | `app.py` の `new_post` |
| 2 | グループ単位の公開範囲（作成・名前変更・メンバー追加／削除・削除） | `new_group` / `edit_group` / `delete_group` |
| 3 | そっと反応（挙手制） | `react` / `unreact` |
| 4 | 匿名段階マッチング | `home` / `post_detail`（人数だけをテンプレートに渡す） |
| 5 | 既読・拒否の非表示 | 既読や「押さなかった」記録をそもそも保存しない |
| 6 | 自動クローズ（揃ったら即確定／揃わなければ静かに終了） | `confirm_if_full` / `close_expired_posts` |
| 7 | 予定の自動チャット化 | `confirm_if_full` でトークを作成、`chat` |
| 8 | 開催確定時のみの通知 | `confirm_if_full` でだけ `notifications` を作成 |
| 9 | 開催決定後の不参加連絡 | `chat`（`kind="absence"`、メンバーにだけ見える） |
| - | 電話帳アクセスの説明画面・拒否時の手入力・未登録者への SMS 招待 | `contacts_permission` / `parse_member_form` / `invite_sms_link` |
| - | アカウント・データの削除 | `account_delete` |

## 元の仕様（Expo＋Firebase）との違い

要件定義書では「Expo（React Native）＋ TypeScript ＋ Firebase」で作る予定になっていますが、
このリポジトリは **Python で作った Web アプリ版** です。そのため、次の部分は「代わりの仕組み」にしています。

| 元の仕様 | この Python 版 |
|---|---|
| iPhone / Android アプリ | スマホのブラウザで使う Web アプリ |
| Firebase（Firestore など） | SQLite（`yurubo.db` ファイル） |
| SMS 認証 | 認証コードを画面とターミナルに表示（本番では Twilio などの SMS サービスにつなぐ） |
| スマホ本体の電話帳 | アプリ内の「電話帳」画面に登録した連絡先 |
| プッシュ通知 | アプリ内の「お知らせ」画面（未読数をナビに表示） |
| アイコン画像 | 絵文字から選ぶ |
| リアルタイムのチャット | 送信・再読み込みで更新 |

## 本番公開の前にやること

- 環境変数 `YURUBO_SECRET_KEY` に、長くて推測されないランダムな文字列を設定する
- 環境変数 `YURUBO_SHOW_SMS_CODE=0` にして、認証コードを画面に出さないようにする
- 本物の SMS 送信サービスにつなぐ（`app.py` の `login` 関数の中）
- `python app.py`（開発用サーバー）ではなく、gunicorn などの本番用サーバーで動かす
- `docs/terms-and-privacy.html` の【　】の部分を埋めて、専門家に確認してもらう
