ゆる募 利用規約・プライバシーポリシー（ドラフト）

このドキュメントについて アプリ「ゆる募」の要件定義（電話帳連携・匿名設計・チャット機能）に合わせて作成したひな形です。私は弁護士ではないため、法的な正確性は保証できません。公開前に、専門家（弁護士など）または信頼できる公式ひな形との照合をおすすめします。 【　】で囲んだ部分は、運営者（あなた）が記入・判断する箇所です。開発環境やバックエンドが確定したら、利用する外部サービスの記載を見直してください。

第1部　利用規約

第1条（適用）

  1. この利用規約（以下「本規約」）は、【運営者名】（以下「運営者」）が提供するスマートフォンアプリ「ゆる募」（以下「本アプリ」）の利用条件を定めるものです。
  2. 本アプリを利用した時点で、利用者は本規約に同意したものとみなします。

第2条（本アプリの内容）

本アプリは、友人・知人など身近な人に対して、遊びや食事などの予定を「ゆるく」募集し、興味のある人だけが反応することで、誘う側・誘われる側の双方が断る／断られる負担を感じにくくすることを目的とした無料のサービスです。

第3条（利用登録）

  1. 利用者は、電話番号による本人確認を行うことで本アプリを利用できます。
  2. 次のいずれかに該当する場合、運営者は登録を承認しないことがあります。
    • 虚偽の情報を登録した場合
    • 過去に本規約に違反したことがある場合
    • その他、運営者が不適切と判断した場合
  3. 【未成年の利用条件：例）18歳未満の方は保護者の同意を得たうえで利用してください　※要検討】

第4条（匿名性に関する仕組み）

  1. 本アプリでは、開催が確定するまでの間、募集の投稿者および反応した人の名前は、他の利用者に表示されません。
  2. 開催が確定した後は、参加者に限り、参加メンバーの名前・アイコンがグループトーク上で表示されます。
  3. 反応しなかった人の情報は、投稿者を含む他の利用者に一切表示されません。
  4. 前各項の仕組みを利用して、他の利用者に対する嫌がらせや、身元を特定する目的での利用を行ってはいけません。

第5条（禁止事項）

利用者は、次の行為をしてはいけません。

  1. 法令または公序良俗に反する行為
  2. 他の利用者や第三者に対する誹謗中傷、嫌がらせ、脅迫、差別的な行為
  3. 出会い系・勧誘・宗教活動・営利目的の宣伝など、本アプリの目的に沿わない募集の投稿
  4. 他人になりすます行為、虚偽の情報を登録する行為
  5. 本アプリのシステムに不正にアクセスする行為、運営を妨害する行為
  6. 電話帳から取得した他人の情報を、本アプリの目的以外に利用する行為
  7. その他、運営者が不適切と判断する行為

第6条（利用制限・登録抹消）

利用者が本規約に違反した場合、運営者は事前の通知なく、投稿の削除、利用の制限、アカウントの停止・削除を行うことがあります。

第7条（サービスの変更・中断・終了）

運営者は、利用者への事前の通知なく、本アプリの内容を変更し、または提供を中断・終了することがあります。これによって利用者に生じた損害について、運営者は責任を負いません（運営者に故意または重大な過失がある場合を除きます）。

第8条（免責事項）

  1. 本アプリは、利用者同士の予定調整を補助するものです。集まりの内容、当日の安全、利用者間のトラブルについて、運営者は関与せず、責任を負いません。
  2. 本アプリは個人が運営する無料サービスであり、常時安定した動作や、情報の完全性・正確性を保証するものではありません。
  3. 【運営者の責任に関する条項：法的な確認を推奨】

第9条（規約の変更）

運営者は、必要に応じて本規約を変更できます。変更後の規約は、本アプリ内または【公開ページのURL】に掲示した時点から効力を生じます。

第10条（準拠法・管轄裁判所）

本規約は日本法に準拠します。本アプリに関して紛争が生じた場合は、【運営者の所在地を管轄する裁判所】を第一審の専属的合意管轄裁判所とします。

第2部　プライバシーポリシー

【運営者名】（以下「運営者」）は、アプリ「ゆる募」（以下「本アプリ」）における利用者の個人情報の取扱いについて、以下のとおり定めます。

1. 取得する情報

本アプリでは、次の情報を取得します。

情報の種類 具体例 取得の目的
電話番号 ログイン時に入力する電話番号 本人確認（SMS認証）、アカウントの識別
プロフィール情報 表示名、アイコン（設定した場合） 開催確定後にメンバーへ表示するため
電話帳の連絡先 連絡先の名前・電話番号（利用者が選択したもののみ） グループの作成、相手への招待
投稿・反応の情報 募集の内容、日時、場所、反応したかどうか 募集・マッチング機能の提供
チャットの内容 開催確定後のグループトークのメッセージ チャット機能の提供
端末情報・通知用トークン 端末の種類、プッシュ通知の送信に必要な識別子 開催確定などの通知の送信

2. 電話帳（連絡先）の取扱い

  1. 電話帳へのアクセスは、利用者が許可した場合のみ行います。許可しない場合でも、電話番号の手入力により本アプリを利用できます。
  2. 電話帳の内容のうち、本アプリが取得・保存するのは、利用者がグループのメンバーとして選択した連絡先の情報のみです。選択していない連絡先の情報は保存しません。
  3. 【電話番号の照合方法：例）電話番号は照合のために変換した形（ハッシュ値）で扱う　※実装時に確定】
  4. 取得した連絡先の情報は、グループの作成および招待の目的にのみ利用し、広告や第三者への販売には利用しません。

3. 利用目的

取得した情報は、次の目的で利用します。

  1. 本アプリの機能（募集、反応、グループ、チャット、通知）の提供
  2. 本人確認および不正利用の防止
  3. お問い合わせへの対応
  4. 本アプリの改善、障害への対応
  5. 利用規約に違反する行為への対応

4. 匿名性の取扱い

  1. 開催が確定するまで、投稿者・反応者の名前は他の利用者に表示しません。
  2. 反応しなかった人の情報は、他の利用者に表示しません。
  3. これらは画面表示だけでなく、データの取得の面でも他の利用者に渡らないよう設計します。
  4. ただし、法令に基づく開示請求があった場合など、法律上必要な場合は、この限りではありません。

5. 第三者への提供・外部サービスの利用

  1. 運営者は、法令に基づく場合を除き、利用者の同意なく個人情報を第三者に提供しません。
  2. 本アプリの提供のため、次の外部サービスを利用することがあります。【開発環境の確定後に記入・修正】
    • データの保存・認証・通知：【例）Google LLC（Firebase）】
    • SMS認証：【例）上記サービスが提供する認証機能】
  3. 外部サービスには、サービス提供に必要な範囲で情報が送信・保存されます。【サーバーの所在国：例）米国など日本国外の場合があります】

6. 情報の保管期間と削除

  1. 取得した情報は、利用目的の達成に必要な期間、保管します。
  2. 利用者は、本アプリ内の「アカウントを削除」機能から、いつでもアカウントと関連するデータの削除を求めることができます。
  3. 削除された情報は、【○日以内】に運営者のサーバーから消去します（法令上保存が必要な情報を除きます）。
  4. 開催確定後のグループトークのメッセージは、【保存期間：例）開催日から○か月後に削除　※要検討】

7. 安全管理

運営者は、取得した個人情報の漏えい、滅失、毀損を防ぐため、アクセス制限や通信の暗号化など、合理的な安全管理措置を講じます。

8. 開示・訂正・利用停止の請求

利用者は、自己の個人情報について、開示・訂正・利用停止・削除を請求できます。下記の連絡先までご連絡ください。ご本人であることを確認のうえ、合理的な期間内に対応します。
