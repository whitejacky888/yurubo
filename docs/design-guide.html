デザインガイド（案5：手書き・コルクボード）

「ゆる募」の画面デザインは、5案のうち 案5：手書き・コルクボード に決定しています。 Claude Codeに実装を依頼する際は、他の案（1〜4）は無視して、このガイドと画面スクリーンショットだけを渡してください。

1. トーン

コルクボードに付箋を貼るような、あたたかみのある手書き風。角のとがったデジタル感をあえて避け、少し斜めに傾いたカードやピンで「掲示板にそっと貼る」感覚を表現する。

2. フォント

  • 書体：Klee One（Google Fonts / 日本語手書き風フォント）
  • 見出し・本文とも同じ書体で統一。ウェイトは通常400、強調は600。
  • React Native実装時は expo-font などでGoogle Fontsを読み込む。

3. カラーパレット

用途 色名 HEX
背景（コルクボード） ベージュ #F1E4C8
カード背景（白系サーフェス） オフホワイト #FBF4E4
付箋カラー1（黄） イエロー #FFE9A8
付箋カラー2（オレンジ系） コーラル #F8C9B4
付箋カラー3（緑系） セージグリーン #CFE3C4

補助テキスト ライトブラウン #8C7454
プレースホルダー文字 くすみベージュ #B49B76
画鋲（ピン）のアクセント レッド #C0392B

4. コンポーネントの特徴

  • 付箋カード：角丸4px、2px境界線（#4E3B27）、わずかな回転（-2deg〜1.5deg程度）でランダム感を出す。上部中央に丸い画鋲アイコンを配置。影は柔らかく（2px 4px 8px rgba(78,59,39,0.18)程度）。
  • ボタン：角丸の大きいピル型（border-radius: 9999px）、2px境界線、塗りは付箋カラーのいずれか。
  • 入力欄：角丸6px、2px境界線、背景はオフホワイト。
  • アイコン：線画（ストローク）のシンプルなアウトラインアイコン、線幅は太め（1.8〜2.4px）。
  • ボトムナビゲーション：画面下部固定、上部に2px境界線、アイコン＋短いラベルの組み合わせ。
  • FAB（＋ボタン）：円形、直径56〜58px、2px境界線、少し傾ける（-4deg程度）ことでアクセントに。

5. 画面一覧（案5で確定している6画面）

# 画面名 内容
1 ホーム画面 自分宛の「ゆる募集」一覧を付箋カードで表示。各カードにタイトル・日時・「気になってる人：◯人」を表示（投稿者名は非表示）
2 誘いをつくる（募集作成） タイトル・日時・場所・公開範囲（グループ選択）・開催人数を入力
3 募集の詳細（投稿者本人視点） 集まり具合（◯/◯人）のみ表示。投稿者にも反応者の名前は見えない
4 開催決定後のグループトーク 人数が揃うと自動生成。ここで初めてメンバーの名前・アイコンが見える
5 見せる相手グループの一覧 登録済みグループ（電話帳連携）を付箋カードで表示。「＋新しいグループを作る」あり
6 新しいグループを作る グループ名の入力＋電話帳の連絡先からチェックボックスで複数選択

6. React Native実装時の注意

  • 上記はWebのモックアップ（HTML/CSS）のため、React Native（Expo）で作る際はスタイルの意図（配色・角丸・余白感・傾き）を再現する形で構わない。DOM構造をそのまま移植する必要はない。
  • 「投稿者・反応者の匿名表示」「気になってる人数のみの表示」は見た目だけでなく、要件定義書のデータ設計（サーバー側で情報を渡さない）とセットで実装すること。

渡し方（Claude Codeへの持ち込み手順）

  1. このファイルをプロジェクトの docs/design-guide.md などに保存する。
  2. 案5の6画面（上記表）を、キャンバス上でスクリーンショットして docs/screens/ に保存する（他の案1〜4は不要）。

  4. Claude Codeを開き、「docs/の要件定義書とデザインガイド、画面スクリーンショットの通りに、Expo＋TypeScriptでプロジェクトを作って」と伝える。
